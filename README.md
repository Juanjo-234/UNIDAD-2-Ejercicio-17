Resolución del ejercicio N°17 de la unidad 2 de programacion 2.
Este programa simula un sistema de carga para vehículos eléctricos que administra la capacidad y el nivel de energía de las baterías, suministrando potencia de manera controlada y deteniendo automáticamente el proceso al alcanzar su capacidad máxima.
